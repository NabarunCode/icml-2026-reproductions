# Benchmarks

Cross-paper benchmark infrastructure and raw run outputs, following the
repo-wide benchmarking standard (root `README.md`): warm-up iterations,
multiple repeated runs, mean and variance reported (not single numbers),
and full environment metadata (OS, CPU, RAM, Python version, dependency
versions) recorded alongside every result.

Raw output belongs here; the curated, written-up numbers that make it into
a claim's verdict belong in that claim's `README.md` under `results/`.

Empty as of Phase 0. First contents expected in Phase 5 for the
Incremental BPE Tokenization paper's Claims 3 and 4 (throughput speedup
and pathological-input robustness).
